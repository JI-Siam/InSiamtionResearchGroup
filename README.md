# InSiamtionResearchGroup

InSiamtion Research Group (IRG) is a student-led research and mentorship community at American International University-Bangladesh (AIUB). We build collaborative teams, mentor capable students, and support publication-focused research projects.

Live demo: https://irg-omega.vercel.app/

## Top features
- Server-rendered homepage with structured JSON content for SEO
- Featured research highlights and publication venues
- Team pages and membership information (recruitment currently paused)
- "Why Join Us" section designed to attract high-potential students
- Modern, responsive card-based UI with accessible components

## Tech used
- Next.js (App Router)
- React
- Tailwind CSS (v4) + daisyUI
- framer-motion, react-countup, react-fast-marquee
- Node.js (backend APIs)
